## ブログ運用のルール(このリポジトリで作業する場合)

- 新しい記事は `npm run new-post -- "タイトル"` で作成する(`posts/`配下にMarkdownファイルが作られる)。
- `npm run build`で静的HTMLを再生成し、`git add -A && git commit && git push`で公開する。
- **投稿前に必ず`posts/`を確認し、今日の日付のファイルが既に存在しないか確認すること**(ローカル側でも同じタスクが動いており、二重投稿を避けるため)。既に今日の分があれば、新規投稿はスキップする。
